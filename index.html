4
Remove VEO Audio
FFmpeg

Strip unwanted VEO-generated audio from the final clip.

ffmpeg -i clip_3.mp4 -an -c:v copy clip_noaudio.mp4

# -an: Remove all audio streams
# -c:v copy: Copy video without re-encoding (INSTANT)
5
Add Custom Audio
FFmpeg

Merge silent video with custom narration audio.

ffmpeg -i clip_noaudio.mp4 -i audio.mp3 \
    -map 0:v -map 1:a -c:v copy -c:a aac \
    -t 18 -shortest clip_final.mp4

💰 Cost Comparison

AWS MediaConvert

  • ~$0.015 per minute of output
  • Additional costs for HD/4K
  • Per-job overhead costs
  • Requires video re-encoding

FFmpeg on AWS VM

  • $0 additional cost (existing VM)
  • No video re-encoding needed
  • Processing time: < 1 second
  • Uses -c:v copy (instant)

📋 Key Findings

  1. VEO 3.1 generates audio by default - cannot be disabled via API
  2. After testing multiple approaches, the only solution is post-processing with FFmpeg
  3. FFmpeg on existing AWS VM is more cost-effective than MediaConvert
  4. Using -c:v copy means no video re-encoding = instant processing
  5. Total audio processing time: < 2 seconds per video
